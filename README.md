# 北海道 8 天 7 夜旅行網站

以手機操作為主的北海道自由行旅遊網站，行程日期為 2026/11/21–11/28，主要城市為札幌、小樽與登別。依 2026/10/28 更新的計畫，共札幌 5 晚、小樽 1 晚、登別 1 晚。

- 線上網站：[caocharles.github.io/2026-sapporo-trip](https://caocharles.github.io/2026-sapporo-trip/)
- 主要入口：`index.html`
- 部署方式：GitHub Pages（`main` 分支）

## 網站特色

- Mobile-first 單頁式 App 介面
- 固定底部導覽列與 Hash 路由
- 每日時間軸、交通、住宿與備案整合
- 景點照片輪播、日文名稱、地址、語音及導航
- 即時天氣、互動地圖與步行路線
- 中／日／英旅遊會話與瀏覽器日文語音
- 行前清單、完成度、重要預訂與個人備忘
- 資料保存在使用者自己的瀏覽器，不需登入或後端服務

## 早餐標示

總覽八日速覽與每日行程上方均顯示早餐狀態，依前一晚住宿判斷，不使用當晚飯店。綠色為已含飯店早餐，琥珀色為方案待確認，灰色為自行安排。11/21 是出發日；11/22 the b、11/23 OMO、11/28 Forza 方案待確認；11/24–25 Comfort、11/26 第一滝本館、11/27 Nest 已安排早餐。海鮮品項另外確認，未確認不等於無早餐。

水族館每日行程詳情與導覽詳情共用四個必看展區及海獸公園時刻表，來源與重要限制見 `docs/2026-10-28-itinerary-sources.md`。長版插畫保留為旅程摘要，新增餐飲與早餐細節以每日行程為準。

## 景點詳情與照片

行程卡與導覽卡使用共用的底部詳情頁，依資料完整度顯示：

- 中文與日文名稱
- 多張照片左右滑動
- 圖片頁數及授權來源
- 建議停留時間與類型
- 詳細日文地址及一鍵複製
- 日文語音播放與名稱複製
- Google Maps 地點與步行導航
- 冬季提醒、景點故事與冷知識

照片優先使用 Wikimedia Commons 等可確認授權的素材；無法確認授權或地點的圖片不會混用，頁面會顯示尚未找到可靠實景照片。

## 旅遊會話

旅遊會話依本次旅程規劃為七類：

- JR／巴士
- 問路與景點
- 叫車
- 住宿
- 餐廳與候位
- 溫泉
- 求助與醫療

每句包含繁體中文、日文與英文，並標示適用場景。日文可直接播放或複製給對方查看。語音使用瀏覽器原生 Web Speech API，實際聲音依裝置可用的日文語音而異。

## 旅行清單

清單分為：

- 重要預訂：住宿、OMO 活動、水族館、登別轉乘、冬季點燈及回程交通
- 證件與付款
- 交通與網路
- 北海道冬季用品
- 隨身用品
- 出發當日確認
- 自訂項目
- 個人備忘錄與快速標籤

舊版 `checks` 清單會在第一次開啟新版時嘗試轉換到 `trip_list_v2`。資料只存在目前瀏覽器的 `localStorage`；更換裝置、清除網站資料或使用無痕模式時不會自動同步。

備忘錄可匯入私人 `.txt` 檔，內容會附加到既有備忘，僅存在目前裝置的瀏覽器。網站不會上傳該檔案。訂房編號、私人費用與航段提醒放在被 Git 忽略的 `private-trip-notes.txt`；所有 PDF（包含收據與訂房文件）均排除於版本控制，不可發布。

## 技術結構

- HTML5
- Tailwind CSS CDN
- Vanilla JavaScript
- Font Awesome
- Leaflet
- `localStorage`
- GitHub Pages

網站不需建置流程或套件安裝，所有主要介面與資料都在 `index.html` 中。

`札幌旅遊App.html` 與主入口保持相同內容；舊的 `札幌行程.html` 會導向最新每日行程，避免顯示已取消的路線。新增照片授權與營業資料來源見 `assets/guide/october/SOURCES.md`。

完整性檢查：`node tests/trip-integrity.cjs`，涵蓋八天日期、六筆住宿對應、景點照片、地圖座標、資產路徑、入口同步及私人檔案排除。

## 本機預覽

可直接開啟 `index.html`，或在專案目錄啟動靜態伺服器：

```bash
python3 -m http.server 8000
```

接著瀏覽：

```text
http://localhost:8000/
```

使用靜態伺服器預覽，能更接近 GitHub Pages 的網路請求與路由行為。

## 部署

網站由 GitHub Pages 直接發布 `main` 分支。更新流程：

1. 修改並檢查 `index.html` 與相關素材。
2. 同步更新本 README。
3. Commit 並 push 至 `origin/main`。
4. 等待 GitHub Pages 約 1–3 分鐘更新。
